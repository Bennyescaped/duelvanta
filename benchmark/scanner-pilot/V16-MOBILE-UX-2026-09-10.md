# V16.14: mobile interaction, first delivery

The owner approved simplifying the scanner while keeping DUELVANTA's original black/gold identity and immutable SVG logo. Work remains isolated to scanner-v16 / Draft PR #1. No production COLLECT, Auth, RLS or real collection data is changed by this delivery.

## Implemented

- Compact Card / Series / Multiple / Binder mode controls with selected state.
- Existing TCG and destination selectors, larger mobile text and touch targets.
- Live start and shutter share one action position according to actual camera state; gallery stays visible. Native photo capture remains reachable under an expandable alternative.
- Name, identifier, language and useful review guidance remain visible. OCR traces, evidence and expanded price details are collapsed by default.
- Selected-card count and disabled save actions for unconfirmed/no-hit cards.
- Save and continue: persists through the existing import, starts the next capture only after success, retains an inline saved-card view. Outstanding unselected results remain visible rather than being discarded by automatically starting another single scan.
- Existing Save action still allows reviewing the saved card before continuing.
- Reduced-motion styling and 16px mobile selectors to avoid focus zoom.

## Validation

All sixteen existing Node suites pass locally. Browser regression coverage adds collapsed-details visibility, reachable native fallback, correct identity in the compact result, and save-and-next recovery after denied camera access. Existing OCR, provider, benchmark, geometry, import and catalog tests remain required. No paid Ximilar requests are needed for this UI delivery.

## Accepted beta rules (not activated)

Per authenticated user, per week starting Monday 00:00 Europe/Berlin:
- 20 normal-card identifications;
- 5 identifications of already graded cards including slab label data;
- no new AI condition grading included.

Internal nominal credit reservations: 10 normal / 15 slab; global account allowance is 100,000 credits per provider billing period, minus already-used credits. Reserve before upstream requests and stop on exhausted global or personal allowance. No automatic credit purchases. A multi/binder image must account for each card submitted, not merely one photo. Separate raw/slab counters and the global ledger replace the earlier small test-only SQL proposal; that proposal must not be applied unchanged.

## Remaining work and release gates

1. Replace the closed test-only quota proposal with the approved weekly raw/slab counters plus global provider-period ledger. Validate concurrent reservation, expiry, duplicate requests, cross-user access and accounting failures before activation. Existing collection/Auth policies stay untouched.

UI completion does not imply paid recognition activation or completed slab/multi/binder enhancements. Main/V15.8 and the original logo remain untouched.
